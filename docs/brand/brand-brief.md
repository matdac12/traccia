# Traccia brand brief

Decisions from the brand foundations session with Mattia. Feeds TRC-73, TRC-74, TRC-75, TRC-76 and TRC-81.

## Positioning

A private, self-hosted issue tracker for one developer and their AI agents.

For a solo developer who runs their own stack and works with coding agents such as Claude Code and Codex. The instance is private and reachable only on your tailnet. The project is open source, shared on GitHub and X.

Deliberately not:

- Not for teams. No collaboration, no shared workspace, no seats.
- Not SaaS. You self-host it. No accounts, no plan, no sign-up.
- Not a general project manager. No roadmaps, cycles, docs, integrations or time tracking.

## Tagline

You and your agents, on the same page. Recommended.

Considered and set aside: "A trail you and your agents share." and "Keep track. Quietly."

## Voice

Calm, precise, a little playful.

- Short declarative sentences, one idea each.
- Name the actor. Write "the agent created this issue", not "the issue was created".
- Dry humour at most. No exclamation marks.

Use: issue, agent, actor, you, project, milestone, label, blocker, sub-issue, comment, attachment, delete, restore, purge, trash, trace, track, trail, quiet, private, self-hosted, tailnet, open source.

Avoid:

- Hype: supercharge, seamless, revolutionise, empower, unleash, effortless, blazing, 10x, "the future of".
- Vocabulary drift, per GLOSSARY.md: ticket, task, user, member, bot, assistant, API key, dependency, subtask, archive.
- Team and SaaS words: team, workspace, collaboration, seats, org, enterprise, plan, subscribe.
- Typography: no em dashes or en dashes, no curly quotes, no filler.

## Name story

Traccia is Italian for a trace, a track, a trail. It is also the outline drawn under a painting, a plotted route, and a lead you follow. Tracciare means to trace, to draw, to follow. The idea behind the product is that work leaves a trace, and you and your agents follow the same trail.

Two kernels come from the name and carry into the visuals.

- The mark, for TRC-73: two traces, one amber for you and one cyan for the agent, on the same trail. The mark encodes the two actors and the two brand colours.
- The motion, for TRC-74: the trail. A line drawing on, a card leaving a faint trail as it moves, the agent's action drawing a line across the board.

Colour stays as the dashboard has it: amber accent by default, cyan for the agent identity, near-monochrome elsewhere.

## What the next issues start from

TRC-73 logo and identity. From the two traces kernel. Amber for you, cyan for the agent. Keep the Linear-calm look. The app icon and favicon come from the mark.

TRC-74 hero shots and film. From the trail motion language. Slow, smooth camera moves, an agent creating issues while the board updates, seeded demo data.

TRC-75 landing page. On hold. No domain is bought and no site is built for now. The README and the GitHub page carry the public face. Revisit only if the project gains traction.

TRC-76 GitHub presence. The priority, and the public face. The repo goes public with a modern README, a one-line pitch, a social preview and a quickstart. Genericize the tailnet hostname, node name and tailnet IP in the public docs. Run a secret scan before flipping visibility, and allowlist or regenerate the committed test key fixture.

TRC-81 launch plan. GitHub-led. The repo is public now, with no announcement. X comes later, when Mattia is ready. Show HN, Product Hunt and MCP directories wait for traction. The self-hosting guide for strangers is separate work.

## Decisions

Resolved after the brief.

- The repo is public now and always open source. The GitHub repository is the public face. No X post or marketing yet. TRC-76.
- The landing page and website are on hold. No domain is bought. TRC-75 stays in the backlog and is revisited only if the project gains traction.
- The launch is GitHub-led. X comes later, when Mattia is ready. Show HN, Product Hunt and MCP directories wait for traction. TRC-81.
- The real tailnet hostname, node name and tailnet IP are genericized in public docs. The private deploy config keeps the real values.

Still open:

- When to post on X, and whether to use Show HN, Product Hunt or MCP directories later. TRC-81.
- Whether the landing page ever gets built. TRC-75, revisit on traction.
