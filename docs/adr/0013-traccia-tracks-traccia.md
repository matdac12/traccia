# Traccia tracks its own work; Linear becomes a read-only archive

Traccia's own backlog moved from Linear to Traccia (project `TRC`, self-hosted on a private tailnet, reached by agents over MCP). The 91 issues of the legacy Linear project were imported once, with status, labels, milestones, sub-issues, blockers and comments; "related" links became a trailing `Related (Linear)` line because Traccia has no such relation. Linear is kept read-only as an archive and is no longer wired into agents for this repo (the Linear MCP is disabled here, and the Linear entry is gone from `opencode.json`). We chose dogfooding over a separate pilot project: real use finds friction fastest. Consequence: agents file, search and close issues through the `traccia` MCP only, and old `MAT-nnn` identifiers are found by searching Traccia for the text.
